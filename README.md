# Aether Data - AI-Powered Autonomous Data Analysis Platform

Aether Data is an enterprise-ready, full-stack AI Data Analysis platform that automates the ingestion, profiling, cleaning, analysis, and visualization of structured datasets. Powered by a coordinated team of LangGraph agents and a FastAPI backend with Next.js frontend.

---

## Technical Stack & Architecture

- **Frontend**: Next.js 13 (App Router), Tailwind CSS, Recharts (Dynamic Interactive SVG Charts), Lucide Icons, Axios.
- **Backend**: FastAPI (Python), SQLModel (SQLAlchemy + Pydantic ORM), SQLite (Local testing) / PostgreSQL + pgvector (Production), Redis (Caching & Task states).
- **AI Core**: LangGraph, LangChain, OpenAI GPT-4o-mini / Heuristic engine fallback.
- **Infrastructure**: Docker, Docker Compose, GitHub Actions CI/CD.

## Local Development Setup

### Backend Local Setup (Without Docker)

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Create and activate a Python virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Copy the environment template and set your LLM API keys:
   ```bash
   cp ../.env.example .env
   ```
5. Start the FastAPI development server:
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```
   Open `http://localhost:8000/docs` to access the interactive Swagger API documentation.

### Frontend Local Setup (Without Docker)

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install npm packages:
   ```bash
   npm install
   ```
3. Start the Next.js development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:3000`.

## Docker Quickstart (Recommended)

To run the entire architecture, including PostgreSQL and Redis databases, in a single command:

1. Clone the project and set up your `.env` keys in the root directory (based on `.env.example`).
2. Build and spin up the containers:
   ```bash
   docker-compose up --build
   ```
3. The application will be accessible at:
   - Next.js Web App: `http://localhost:3000`
   - FastAPI REST API: `http://localhost:8000`

## Security Implementation Features

1. **Sandboxed Code Execution**: Any Pandas query generated by the AI Chat agent runs inside a customized, isolated Python scope that blocks modules imports (like `os`, `sys`, `subprocess`) to prevent Remote Code Execution (RCE).
2. **JWT & Bcrypt**: Password hashing using bcrypt and stateless authentication using secure JWT tokens.
3. **Database Security**: Direct parameters binding via SQLAlchemy/SQLModel to prevent SQL Injection vectors.
